# Virtuelles Klassenzimmer – Blockwoche 1

Dateien:
- `index.html` – Startseite mit klickbarem Plakat
- `style.css` – Gestaltung
- `script.js` – Interaktionen

## GitHub Pages
1. Neues Repository anlegen.
2. Die drei Dateien ins Hauptverzeichnis hochladen.
3. Unter **Settings → Pages** bei **Build and deployment** „Deploy from a branch“ wählen.
4. Branch `main` und Ordner `/ (root)` auswählen.
5. Speichern.

Danach öffnet GitHub Pages die `index.html` automatisch.

Hinweis: Das Plakatbild ist direkt in der `index.html` eingebettet. Es wird daher keine zusätzliche Bilddatei benötigt.
